# Payanam – Travel Website

Payanam is a custom travel website created as part of my Full Stack Developer course.

This website was designed using my own creativity and ideas, while taking inspiration from different travel websites and combining various features into a unique layout.

## Features

- Responsive navigation bar
- Hero section with travel search
- Explore categories
- Popular experiences
- Travel destinations
- Hotels and stays
- Image hover and zoom effects
- Travel inspiration section
- Newsletter section
- Responsive design for desktop and mobile
- Social media footer

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome
